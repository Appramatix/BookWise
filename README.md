# BookWise
A Smart Equipment and Room Reservation System with Real-Time Conflict Detection (Django)
## About
BookWise is a web-based reservation system for rooms and equipment. Beyond basic
record management, it detects booking conflicts automatically, suggests free slots,
shows live availability, and gives usage insights. The interface is designed around
Nielsen's usability heuristics (HCI).

## Tech Stack
- Python, Django
- HTML, CSS, JavaScript
- SQLite / MySQL
- Cloudflare Tunnel (hosting from a local machine)

## Planned Features
- Role-based login (admin, staff, borrower)
- Room and equipment management
- Reservations with conflict detection and free-slot suggestions
- Live availability dashboard
- Auto-rules (no-show expiry, overdue flags)
- Usage charts and activity log
